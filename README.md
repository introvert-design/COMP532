# Machine Learning and Bioinspired Optimisation – Coursework Projects

This repository showcases a collection of academic projects and assignments developed as part of a university-level course in **Machine Learning** and **Bioinspired Optimisation**. It reflects hands-on experience with both traditional ML techniques and nature-inspired algorithms, with a strong emphasis on practical implementation and problem-solving.

## Key Topics Covered
- Supervised & Unsupervised Learning (e.g., Regression, Classification, Clustering)
- Neural Networks & Deep Learning
- Dimensionality Reduction (PCA, t-SNE)
- Evolutionary Algorithms (Genetic Algorithms, Evolution Strategies)
- Swarm Intelligence (e.g., Particle Swarm Optimization, Ant Colony Optimization)
- Model Evaluation & Optimization Techniques

## Technologies Used
- Python
- NumPy, pandas, scikit-learn, matplotlib, seaborn
- TensorFlow / PyTorch (where applicable)
- Jupyter Notebooks

## Highlights
- End-to-end implementation of ML models with data preprocessing, training, validation, and evaluation
- Custom implementations of bioinspired algorithms from scratch
- Well-documented code and clearly visualized results
